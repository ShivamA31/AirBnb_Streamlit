# AirBnb_Streamlit

Interactive Airbnb listing analytics dashboard built with Python, Streamlit, Pandas and Plotly.

## Run locally

```bash
cd lab6
pip install -r requirements.txt
streamlit run Airapp.py
```

The app reads `lab6/airbnb.csv`. On Streamlit Community Cloud, set the main file to `lab6/Airapp.py`.
